### <a name="_qmphm5d6rvi3"></a>**Решение**

Приведите диаграммы контекста и контейнеров в модели C4. Опишите там основные компоненты и интеграции всех элементов решения. 

**Обоснование архитектурных решений:**

Двойной механизм передачи данных:
REST API для внутреннего кол-центра - минимальная задержка, реальное время
SFTP + файлы для партнера - соответствует ограничениям партнерской системы

Кэширование ставок в Redis:
Снижение нагрузки на АБС
Быстрый отклик для API запросов
Автоматическое обновление при изменении в АБС

Механизм гарантированной доставки файлов:
Ретрай при ошибках передачи
Подтверждение получения
Мониторинг актуальности данных

Безопасность передачи:
Шифрование файлов с ставками
Аутентификация по SSH-ключам
Проверка целостности данных

### <a name="_bjrr7veeh80c"></a>**Альтернативы**

Альтернатива 1: Единый REST API для всех кол-центров
Плюсы: Упрощение архитектуры, единый механизм обновления
Минусы: Не соответствует ограничениям партнерского кол-центра (нет API)

Альтернатива 2: Репликация базы данных ставок
Плюсы: Высокая производительность, минимальная задержка
Минусы: Сложность реализации, риски безопасности, нарушение изоляции систем

Альтернатива 3: Push-уведомления об изменении ставок
Плюсы: Максимальная актуальность данных
Минусы: Сложность обработки сбоев, избыточность для партнера


**Недостатки, ограничения, риски**

Технические риски:
Задержка обновления у партнера - файловая синхронизация менее оперативна, чем API
Митогация: Увеличение частоты выгрузки до 1 раза в 5 минут
Безопасность файлов на SFTP - риск перехвата данных
Митогация: Шифрование файлов, регулярная ротация ключей
Нагрузка на сервис депозитов - увеличение количества интеграций
Митогация: Кэширование, горизонтальное масштабирование

Бизнес-риски:
Некорректные ставки у партнера - финансовые и репутационные потери
Митогация: Валидация файлов, мониторинг расхождений
Неготовность партнера к приему файлов - срыв сроков MVP
Митогация: Раннее вовлечение партнера, тестовая интеграция

Ограничения:
Партнерский кол-центр не может принимать API вызовы
Максимальный размер файла 10MB (ограничение партнера)
Только SFTP протокол для передачи файлов
